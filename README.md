# Yukitoito_practic2
Каталог видеоигр

    Простой каталог видеоигр с возможностью добавления, редактирования и удаления.

Как запустить

    1. Скачайте все файлы
    2. Откройте `index.html` в браузере

Главная страница

    Смотрите все игры
    Ищите игры по названию или жанру
    Нажмите на карточку для просмотра деталей

Админка

    Нажмите "АДМИНКА" в меню
    Добавить: заполните форму и нажмите "СОХРАНИТЬ"
    Изменить: нажмите "ИЗМЕНИТЬ" у игры
    Удалить: нажмите "УДАЛИТЬ"

Технологии
